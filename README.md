# 🚌 Bus Ticket Booking System

A simple online bus ticket booking website built using HTML, CSS, and JavaScript.

## 📌 Project Description

This project allows users to search for buses based on their source, destination, and travel date. Users can select a bus, choose their seats, enter passenger details, and confirm their booking.

## ✨ Features

- Search buses by source and destination
- Select travel date
- Display available buses
- View bus details
- Select seats
- Automatic fare calculation
- Enter passenger details
- Generate a booking ID
- Display booking confirmation

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
